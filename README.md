# E-commerce Trend Analysis
Structured Query Language (SQL) is essential for managing and analyzing vast amounts of e-commerce data, enabling businesses to make data-driven decisions that enhance customer satisfaction, optimize inventory and improve overall performance. 
# Aim
The goal is to help the organization to better understand the factors that contribute to employee health and wellbeing using EDA and follow this steps:
1) Understand the Dataset - Familiarize with the dataset’s context, structure and variables to comprehend its overall purpose and scope.
2) Data Preprocessing - Clean, transform and prepare the dataset to ensure it is ready for analysis by handling missing values, outliers and inconsistencies.
3) Exploratory Data Analysis - Analyze and visualize the data to uncover patterns, relationships and insights that inform further analysis.
4) Insights and Interpretation - Summarize key findings from the analysis and discuss their implications in the context of the dataset's purpose.
